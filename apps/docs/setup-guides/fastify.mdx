<Warning>
The JavaScript SDK (`apilens-js-sdk`, v0.1.x) is **beta**. The Fastify plugin is tested with Fastify 5 on Node 18+.
</Warning>

## Install

```bash
npm install apilens-js-sdk
```

## Register the plugin

```javascript
import Fastify from "fastify";
import { apiLensFastify } from "apilens-js-sdk/fastify";

const app = Fastify();

await app.register(apiLensFastify, {
  apiKey: process.env.APILENS_API_KEY,
  appId: "storefront-api",        // your service's name; the app appears on first data
  environment: "production",
});

app.get("/orders/:id", async (request) => {
  return { id: request.params.id };
});

await app.listen({ port: 3000 });
```

Register the plugin at the root, **before** your routes. It skips Fastify's encapsulation (like `fastify-plugin`), so it covers every route of the app, including routes in plugins registered with a `prefix`. If you would rather not use `register`, `instrumentFastify(app, config)` attaches the same hooks and returns the client.

The plugin captures each request on Fastify's own hooks: `onRequest` starts the capture and the trace, `onSend` reads the response payload, `onError` keeps a thrown error for the error log, and `onResponse` records the request. Requests are grouped by the route that matched (`request.routeOptions.url`), so `/orders/42` and `/orders/43` both count towards `/orders/{id}`.

## Identify consumers

Set the consumer on the request once your auth hook knows who is calling:

```javascript
import { setConsumer } from "apilens-js-sdk/fastify";

app.addHook("preHandler", async (request) => {
  if (request.user) {
    setConsumer(request, { id: request.user.id, name: request.user.email, group: request.user.plan });
  }
});
```

A string works too (`setConsumer(request, "acme-corp")`), or pass a centralized `getConsumer(request, reply)` resolver in the config.

## Options

The plugin takes the same options as the [Express middleware](/setup-guides/express): delivery (`batchSize`, `flushIntervalMs`, `maxQueueSize`, …), header and body capture (`requestLogging`, `captureProfile`), redaction, exclusions, sampling and tracing. Every option can also be set with its `APILENS_*` environment variable.

## Capture posture

`captureProfile` picks what leaves the process in one word: `metadata` (no headers or bodies), `redacted` (headers and bodies with the default masking, 16 KB body cap) or `full` (the default). Every profile still sends the base record, so metrics and dashboards stay exact. For a first production rollout, start on `metadata`:

```javascript
await app.register(apiLensFastify, {
  apiKey: process.env.APILENS_API_KEY,
  appId: "storefront-api",
  captureProfile: "metadata",     // metadata | redacted | full
});
```

An explicit option wins over the environment, so for a rollout leave the profile out of code and set `APILENS_CAPTURE_PROFILE` instead: the posture can then be widened or tightened with a redeploy. `metadata` still sends the URL with its query string, so add a `redactQueryParams` pattern for any parameter that carries personal data. See [Capture profiles](/getting-started/data-privacy#capture-profiles) and [phase 2 of the rollout guide](/guides/third-party-rollout#phase-2-capture-posture).

## Environment variables

Every option has an `APILENS_*` variable, with the Python SDK's names, so keys, posture and patterns stay out of code. A typical deployment:

```bash
APILENS_API_KEY=apilens_...          # project key, from your secret store
APILENS_APP_ID=storefront-api
APILENS_ENVIRONMENT=production
APILENS_CAPTURE_PROFILE=metadata     # metadata | redacted | full
APILENS_REDACT_QUERY_PARAMS=^email$,token
# Kill switch. Wins over code, in the direction that captures less:
# APILENS_CAPTURE_SPANS=false        # no spans or error-trace logs
```

Precedence is **explicit option > env var > default**. `APILENS_ENABLED=false` turns the SDK off on the next deploy, as long as `enabled` is not set in code ([SDK runbook](/guides/sdk-runbook#stop-capture-kill-switch)). The JavaScript SDK always sends the client IP in full: `APILENS_CAPTURE_IP` and `APILENS_ANONYMIZE_IP` are not read yet. The full list is in the SDK's [environment variable reference](https://github.com/apilens/apilens/blob/v2/packages/sdk-typescript/README.md#environment-variables).

## Shut down cleanly

Flush buffered records before the process exits:

```javascript
app.addHook("onClose", async () => {
  await app.apilensClient?.handleShutdown({ flush: true });
});
```

## Verify

Send a few requests and open the **Traffic** page — your Fastify app's endpoints appear with their route templates alongside your other services in the project.
