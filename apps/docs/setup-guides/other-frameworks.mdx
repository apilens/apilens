No first-class integration for your stack? You still have three good options before falling back to the raw [Ingest API](/ingest/ingest-api).

## Generic ASGI middleware

Works with any ASGI application (Quart, Sanic in ASGI mode, custom frameworks):

```python
import os
from apilens import ApiLensClient, ApiLensConfig
from apilens.client.middleware import ApiLensASGIMiddleware

client = ApiLensClient(ApiLensConfig(api_key=os.environ["APILENS_API_KEY"]))
app = ApiLensASGIMiddleware(app, client=client, app_id="custom-api")
```

## Generic WSGI middleware

Works with any WSGI application (Bottle, Pyramid, CherryPy, plain WSGI):

```python
from apilens.client.middleware import ApiLensWSGIMiddleware

app = ApiLensWSGIMiddleware(app, client=client, app_id="legacy-api")
```

Both accept the full set of capture options (`enable_request_logging`, `capture_headers`, `capture_spans`, `max_payload_bytes`, `get_consumer`, `route_resolver`, `parametrize_paths`, …) documented in the [configuration reference](/sdk-reference/python-configuration).

<Tip>
Without framework route information, path templating falls back to the heuristic (numeric IDs, UUIDs, hashes → `{id}`, `{uuid}`, `{hash}`). If your URLs contain other variable segments, pass a `route_resolver` callback to return the template yourself.
</Tip>

## Capture posture

`capture_profile` picks what leaves the process in one word: `metadata` (no headers or bodies), `redacted` (headers and bodies with the [default masking](/getting-started/data-privacy#default-masking-patterns), 16 KB body cap) or `full` (the default). Every profile still sends the base record, so metrics and dashboards stay exact. For a first production rollout, start on `metadata`:

```python
app = ApiLensASGIMiddleware(app, client=client, app_id="custom-api", capture_profile="metadata")
```

An explicit argument wins over the environment, so for a rollout leave the profile out of code and set `APILENS_CAPTURE_PROFILE` instead: the posture can then be widened or tightened with a redeploy. `metadata` still sends the URL with its query string, so add a `redact_query_params` pattern for any parameter that carries personal data. See [Capture profiles](/getting-started/data-privacy#capture-profiles) and [phase 2 of the rollout guide](/guides/third-party-rollout#phase-2-capture-posture).

## Environment variables

Every option has an `APILENS_*` variable of the same name, so keys, posture and patterns stay out of code. A typical deployment:

```bash
APILENS_API_KEY=apilens_...          # project key, from your secret store
APILENS_APP_ID=custom-api
APILENS_ENVIRONMENT=production
APILENS_CAPTURE_PROFILE=metadata     # metadata | redacted | full
APILENS_ANONYMIZE_IP=true            # truncate client IPs to /24 (IPv4), /48 (IPv6)
APILENS_REDACT_QUERY_PARAMS=^email$,token
# Kill switches. These win over code, in the direction that captures less:
# APILENS_CAPTURE_IP=false           # send no client IP
# APILENS_CAPTURE_SPANS=false        # no spans or error-trace logs
```

Precedence is **explicit argument > env var > default**. `APILENS_ENABLED=false` turns the SDK off on the next deploy, as long as `enabled` is not set in code ([SDK runbook](/guides/sdk-runbook#stop-capture-kill-switch)). The full list is in [Environment variables](/sdk-reference/python-configuration#environment-variables).

## Manual capture

For workers, cron jobs, or anything that isn't an inbound HTTP request, record events directly:

```python
from apilens import ApiLensClient, ApiLensConfig

with ApiLensClient(ApiLensConfig(api_key=os.environ["APILENS_API_KEY"])) as client:
    client.capture(
        app_id="nightly-sync",
        method="POST",
        path="/jobs/sync",
        status_code=200,
        response_time_ms=1543.0,
    )
# the context manager flushes on exit
```

## OpenTelemetry exporter

Already running OTel instrumentation? Attach APILens as an exporter on your existing tracer provider instead of using the SDK's built-in tracing:

```python
from apilens import install_apilens_exporter

install_apilens_exporter(client, app_id="orders-api", service_name="orders")
```
