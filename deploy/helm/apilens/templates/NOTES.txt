  1. Open the dashboard ({{ default "http://localhost:3000 via the port-forward above" (include "apilens.webPublicUrl" .) }})
     and sign up with your email address.
{{- if eq .Values.email.provider "log" }}
  2. Email delivery is off (email.provider=log), so read the sign-in code from
     the {{ $identityRole }} pod log:

       kubectl -n {{ .Release.Namespace }} logs --tail=-1 --prefix \
         -l app.kubernetes.io/instance={{ .Release.Name }},app.kubernetes.io/component={{ $identityRole }} \
         | grep "email (log provider"

     Set email.provider=smtp (plus email.host, email.from and the
     smtp-password secret key) to deliver sign-in codes by email.
{{- else }}
  2. Enter the sign-in code emailed to you from {{ .Values.email.from }}.
{{- end }}
  3. Create your organization and project; the onboarding flow issues the
     ingest API key for your SDK.
